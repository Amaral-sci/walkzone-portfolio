# Escopo público e segurança

Este repositório é uma apresentação do WalkZone. Não contém o backend nem o projeto iOS de produção.

Não publique em issues ou pull requests senhas, tokens, comprovantes Apple, informações de contas, rotas privadas ou dados de participantes. Para relatar um problema que envolva informações privadas, use o contato disponível na [página de suporte](https://www.walkzone.com.br/suporte/).

As imagens e a documentação não autorizam acesso a ambientes internos. As descrições das práticas de segurança não constituem certificação independente.
